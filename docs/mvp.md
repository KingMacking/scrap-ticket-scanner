# 🚀 MVP Scope

## ✅ Incluye

- Subida de imagen/PDF
- OCR de ticket
- Extracción de pesos
- Generación de ticket digital
- Edición de:
  - peso/cantidad
  - precio
- Impresión de ticket

---

## ❌ No incluye

- Roles complejos
- Dashboard
- Estadísticas
- Integración stock
- Cámara en vivo
- OCR avanzado con IA

---

# 🎯 Objetivo del MVP

Un usuario puede:

1. Subir un ticket escaneado
2. Obtener datos automáticamente
3. Corregir errores manualmente
4. Imprimir ticket final
